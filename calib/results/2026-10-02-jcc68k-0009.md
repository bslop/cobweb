# jcc68k code quality, platform issue 0009 (2026-10-02)

68000 cycles of four small C programs in jsim, from `_start` to the halt spin, display
off (OP on a bare STOP list). The programs are `BENCH_0009` in
`sim/crates/jcc68k/src/tests.rs`; startup and runtime are the same for both compilers.

```sh

cargo test --release -p jcc68k bench_issue_0009 -- --ignored --nocapture
# edition 2026-10-02's compiler
JCC68K=/path/to/cobweb-2026-10-02/bin/jcc68k \
  cargo test --release -p jcc68k bench_issue_0009 -- --ignored --nocapture
```
