# GameDrive writes from the console: platform bench jobs 313-344, 2026-10-12

Bench Jaguar (NTSC), GameDrive firmware `$0115`, BIOS `$0100`. The program is the clean
platform repository's `bench/gdwrite` (game-free), built with the cobweb-2026-10-06 tools on
lib/jag and lib/gd with `gd_fwrite` (BIOS call 14, `GD_FileWrite`). The display (a 16bpp
320x200 bitmap) and lib/jag's DSP mixer (a looped voice and a 32 KB streamed ring) run
throughout. Each call is timed by the mixer's sample counter (15,388 Hz, 864 68000 clocks a
sample), which the DSP keeps independently of the 68000's interrupts. Platform issue 0015.

## What silicon does

- `GD_FOpen` with `GD_FOPEN_WRITE | GD_FOPEN_OPEN_EXISTING`, then `GD_FWrite`, then
  `GD_FClose` overwrites a file in place. `GD_FOPEN_WRITE | GD_FOPEN_CREATE_ALWAYS` creates
  one, at the root or in a directory by path (`/<dir>/<name>`). A seek before a write works.
  Every write read back exact (jobs 313, 323, 324, 344).
- 771 bytes from an odd DRAM address, and 512 bytes from the cartridge window, were written
  exact (job 324).
- With a GPU host running and `GD_InitGPURead`'s handler installed, a write works and leaves
  the vector at `$F03010` alone; so does a write after a GPU-mode async read has finished
  (job 324). With the GPU halted throughout, writes work (job 313): a write doesn't use the
  GPU.
- The files read back exact after a reset to the menu (job 316) and after a power cycle
  (job 318), and the GameDrive menu lists them.
- During a write the field count kept pace with the sample clock (8 KB: 11-12 fields while
  2,968-2,979 samples = 11.6 fields passed), so the 68000 takes its interrupts during the
  call, as during reads. The DSP and the display ran on, with no ring underrun.
- **A power cut during an 8 KB rewrite** (three cuts, jobs 336-341) left the file with a
  prefix of new 512-byte sectors over the old ones (10, 2 and 14 of 16 new), never a torn
  sector, and every other file intact and listed.

**Model** (`gamedrive.rs`, `write_cost`, `OPEN_*`, `SEEK_CLOCKS`, `CLOSE_*`): a write costs
27,000 clocks plus 308 a byte, held in interruptible slices like a read. An open costs 25,000
clocks (35,000 creating a file, 112,000 truncating one, plus 50,000 a directory when it opens an
existing file); a seek 14,700; a close 45,000 after an overwrite, 112,000 after the file was
created or grew. Before, jsim had no call 14, and opens, seeks and closes were free.

The released edition `cobweb-2026-10-06` runs the same ROM with the sample counter stuck at 0:
the DSP's I2S interrupt fired only while jagemu recorded audio. That is fixed separately
(scheduler.rs).
